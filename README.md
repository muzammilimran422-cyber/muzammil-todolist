# Todo List 📝

A simple and responsive Todo List web application built with **HTML, CSS, and JavaScript**.

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📱 Responsive design
- 🎨 Clean and simple interface
- ⚡ Built with vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
